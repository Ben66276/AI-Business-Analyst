# AI 智能经营分析助手（AI Business Analyst）

> 基于大语言模型与数据分析技术的智能企业经营决策辅助系统

![项目界面原型图](docs/images/dashboard.png)

> 注：上图为产品设计原型，图中指标为演示数据，当前不代表已实现的系统功能。

## 一、项目背景与需求分析

企业管理者经常需要了解销售情况、商品表现、库存状态和经营趋势。传统方式通常依赖人工整理 Excel、编写 SQL 和制作图表，存在数据查询效率低、分析成本高、数据利用不充分以及决策不够及时等问题。

本项目计划开发一个结合大语言模型与数据分析技术的智能经营分析助手，让用户通过自然语言完成经营数据查询、分析和辅助决策。

## 二、项目目标

- 通过自然语言查询企业经营数据。
- 自动分析销售数据及变化趋势。
- 通过图表展示核心经营指标。
- 识别异常销售情况和库存风险。
- 根据分析结果生成经营建议。

## 三、核心功能设计

### 1. AI 自然语言问数

用户无需掌握 SQL，通过自然语言提问，例如：

- 最近三个月的销售额分别是多少？
- 哪种商品的销量最高？
- 哪个地区的销售额下降最明显？
- 本月销售额相比上月增长了多少？

系统理解问题、生成受控的数据库查询、执行查询并返回结果。

### 2. 经营数据可视化

- 销售额变化趋势图
- 商品销量排行榜
- 不同地区销售额对比
- 商品销售占比
- 核心经营指标看板

### 3. 智能经营分析

- 识别销售额异常波动
- 分析商品销量变化
- 比较不同时间段的经营表现
- 发现潜在经营问题
- 生成有数据依据的优化建议

### 4. 库存预警与补货建议

结合商品库存和历史销售数据，识别库存不足风险，估算库存可支撑天数，并提出补货参考建议。

### 5. 自动生成经营报告

汇总核心指标、销售趋势、商品表现、异常情况和经营建议，形成结构化报告。

## 四、典型使用场景

用户提问：

> 分析最近三个月的销售情况，找出销量下降最明显的商品，并给出改进建议。

系统处理流程：

1. 理解问题，识别时间范围、商品维度和销量指标。
2. 将查询意图转换为经过校验的 SQL。
3. 从数据库读取销售记录。
4. 使用 Pandas 进行统计计算。
5. 通过图表展示销售趋势和商品对比。
6. 根据查询结果生成分析说明和建议。

## 七、项目特点与价值

1. **自然语言交互：** 降低非技术人员使用经营数据的门槛。
2. **AI 与数据分析结合：** 从简单查询扩展到趋势分析和异常解释。
3. **可视化展示：** 将经营数据转化为直观图表。
4. **辅助经营决策：** 提供有数据依据的参考建议。
5. **模块化设计：** 便于后续扩展更多分析场景。
